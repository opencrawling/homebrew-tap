Official Homebrew Tap for the **OpenCrawling CLI (`oc`)** on macOS and Linux.

## 🚀 Installation

```bash
# 1. Add the OpenCrawling tap
brew tap opencrawling/tap

# 2. Trust the third-party tap (required on Homebrew 7+)
brew trust opencrawling/tap

# 3. Install the OpenCrawling CLI (oc)
brew install opencrawling/tap/oc
```

## 🔍 Verification

```bash
oc --version
oc --help
```
