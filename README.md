# Homebrew Tap for OpenCrawling 🍺

Official Homebrew Tap for OpenCrawling command-line tools.

## 🚀 Installation

```bash
  # Add the OpenCrawling tap
  brew tap opencrawling/tap

  # Install the oc CLI
  brew install oc

## 🔍 Verification

  oc --version
  oc --help
